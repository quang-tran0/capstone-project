# Hướng dẫn cho RTL

- Áp dụng cho `hw/rtl/**`. Khi thêm hoặc sửa RTL, phải chạy kiểm tra timing bằng Vivado sau place-and-route cho FPGA trên KV260 (`xck26-sfvc784-2LV-c`), tại clock mục tiêu của thiết kế. Dùng script phù hợp trong `hw/synth/` hoặc cập nhật script để bao phủ RTL thay đổi. Trước khi báo hoàn tất, kiểm tra setup, hold và pulse width trong `timing_target.rpt`; báo clock, WNS/TNS, WHS/THS và đường dẫn report. Đồng thời chạy `report_utilization` sau place-and-route và báo số lượng, tỷ lệ sử dụng LUT, FF, DSP, BRAM (cùng các tài nguyên khác nếu có) so với tài nguyên FPGA đích; lưu và dẫn đường tới report tài nguyên. Không tự giảm clock để coi là đạt. Nếu chưa chạy được, nêu rõ lý do và không khẳng định timing đạt. Đây là kiểm tra timing cho FPGA đích, không thay thế kiểm thử trên board thật.

- các file như hw/rtl/qkv_projection_q16.sv, hw/rtl/layernorm_q16_pipelined.sv, hw/rtl/embedding_norm_qkv.sv, hw/rtl/dynamic_quantize_q16.sv chỉ là các file tham khảo, không phải là các file RTL chính thức. Không được coi là các file RTL chính thức, không được dùng để synthesize hoặc implement trên FPGA. Chúng chỉ dùng để tham khảo, học tập và nghiên cứu. Cần làm những module RTL chính thức, chạy timing và báo cáo timing, resource utilization theo hướng dẫn trên. Các file RTL chính thức sẽ được duyệt và cập nhật trong repo chính thức.
